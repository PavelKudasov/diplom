## 🎯 Что такое GeoDraw?

**GeoDraw** — это программа для рисования геометрических фигур и построений. Представь что у тебя есть волшебный лист бумаги, на котором можно:

- ✏️ Рисовать любые фигуры (треугольники, круги, квадраты)
- 📐 Строить медианы, биссектрисы, перпендикуляры
- 🔄 Вращать и двигать фигуры
- 📱 Работать и на компьютере, и на телефоне

**Это как чертёж в школе, только на экране и намного удобнее!**

## 🚀 Как запустить?

### На компьютере (Windows/Mac/Linux):

1. **Открой папку** `diplom` на рабочем столе
2. **Найди файл** `index.html`
3. **Дважды кликни** по нему — откроется в браузере

**ИЛИ** (продвинутый способ):
```bash
# Открой командную строку в папке проекта
python -m http.server 8000

# Открой в браузере: http://localhost:8000/
```

### На телефоне (Android/iPhone):

1. **Открой браузер** (Chrome, Safari)
2. **Введи адрес** компьютера (если открыл через сервер)
3. **ИЛИ** просто открой файл `index.html`

## 📐 Фигуры

### 2D Фигуры (плоские):

#### 1. **Точка** 📍
- Самая простая фигура
- Используется для построений

#### 2. **Прямая** 📏
- Бесконечная линия
- Можно вращать

#### 3. **Луч** ➡️
- Линия с началом, но без конца
- Есть стрелочка

#### 4. **Отрезок** ⏺️
- Линия с началом и концом

#### 5. **Угол** ∠
- Два луча из одной точки
- Показывает величину угла

#### 6. **Треугольник** 🔺
- 3 стороны, 3 угла
- Сумма углов = 180°

#### 7. **Прямоугольник** ▭
- 4 прямых угла
- Противоположные стороны равны

#### 8. **Квадрат** ⬜
- Все стороны равны
- Все углы прямые

#### 9. **Ромб** ◇
- Все стороны равны
- Углы не обязательно прямые

#### 10. **Окружность** ⭕
- Все точки на одинаковом расстоянии от центра

#### 11. **Параллелограмм** ▱
- Противоположные стороны параллельны

#### 12. **Трапеция** ⏢
- Только две стороны параллельны

#### 13. **Многоугольник** ⬡
- Любое количество сторон (3-20)

#### 14. **Вектор** ➤
- Направленный отрезок
- Показывает направление и длину

## ⚙️ Построения

### Что такое построения?

**Построения** — это дополнительные линии которые ты добавляешь к фигуре (медианы, биссектрисы и т.д.)

### Как сделать построение:

1. **Выбери фигуру** (кликни по ней)
2. **Нажми кнопку** "Инструменты" внизу
3. **Выбери построение** (медиана, биссектриса...)
4. **Кликни по вершине** фигуры
5. **Готово!** Построение появилось!

---

### 1. **Медиана** 📐

**Что это:** Линия из вершины треугольника к середине противоположной стороны.

**Как построить:**
```
1. Выбери треугольник
2. Инструменты → Медиана
3. Кликни на вершину
4. ✅ Появится линия к середине противоположной стороны
```

**Для каких фигур работает:**
- ✅ Треугольник
- ✅ Многоугольник
- ✅ Угол

---

### 2. **Биссектриса** ✂️

**Что это:** Линия которая делит угол пополам.

**Как построить:**
```
1. Выбери фигуру
2. Инструменты → Биссектриса
3. Кликни на вершину угла
4. ✅ Появится линия ровно посередине угла
```

**Для каких фигур работает:**
- ✅ Треугольник
- ✅ Многоугольник
- ✅ Угол

---

### 3. **Перпендикулярный биссектор** ⟂

**Что это:** Линия которая проходит через середину отрезка под углом 90°.

**Как построить:**
```

2. Инструменты → Перпендикулярный биссектор
3. Кликни на две точки (концы отрезка)

```

```
3. Кликни на первую точку

```

## ✂️ Сечения

### Что такое сечение?

**Сечение** — это "разрез" 3D фигуры. Представь что ты режешь фигуру ножом и смотришь на разрез.

### Как сделать сечение:

```
1. Включи 3D режим
2. Создай 3D фигуру (куб, пирамида...)
3. Инструменты → Сечение
4. Кликни на ПЕРВУЮ точку на фигуре
5. Кликни на ВТОРУЮ точку
6. Кликни на ТРЕТЬЮ точку
7. ✅ Появится треугольник сечения!
```

### Куда можно ставить точки:

- ✅ **Вершины** (зелёные кружки) — притягиваются автоматически
- ✅ **Рёбра** (зелёные линии) — притягиваются автоматически
- ✅ **Любое место на поверхности** — точка появится точно там!

### Советы для сечений:

1. **Ставь точки подальше друг от друга** — сечение будет больше
2. **Используй вершины** — легче попасть (60-80px радиус)
3. **На телефоне** пороги больше (80px вершины, 60px рёбра)

## 📐 Математика в проекте

### 1. **Координатные системы**

```javascript
// Экран → Мир
function screenToWorld(x, y) {
  const cx = canvasEl.clientWidth / 2;
  const cy = canvasEl.clientHeight / 2;
  return { x: x - cx, y: cy - y };  // Y инвертирован!
}

// Мир → Экран
function worldToScreen(wx, wy) {
  const cx = canvasEl.clientWidth / 2;
  const cy = canvasEl.clientHeight / 2;
  return { x: wx + cx, y: cy - wy };
}
```

**Почему так:**
- Центр канваса = (0, 0) в мировых координатах
- Y инвертирован (вверх = положительно)

---

### 2. **3D Проекция**

```javascript
// Перспективная проекция
function project3D(point) {
  const FOV = 500;  // Поле зрения
  const VIEWER_DISTANCE = 400;
  const scale = FOV / (FOV + point.z + VIEWER_DISTANCE);
  return {
    x: point.x * scale,
    y: point.y * scale,
    scale: scale
  };
}
```

**Как работает:**
- Объекты дальше = меньше
- FOV = угол обзора (500 пикселей)
- VIEWER_DISTANCE = расстояние от "камеры"

---

### 3. **Вращение в 3D**

```javascript
function rotatePoint3D(point, rotX, rotY, rotZ) {
  let { x, y, z } = point;
  
  // Вращение вокруг X
  let cos = Math.cos(rotX), sin = Math.sin(rotX);
  let y1 = y * cos - z * sin;
  let z1 = y * sin + z * cos;
  y = y1; z = z1;
  
  // Вращение вокруг Y
  cos = Math.cos(rotY); sin = Math.sin(rotY);
  let x1 = x * cos + z * sin;
  z1 = -x * sin + z * cos;
  x = x1; z = z1;
  
  // Вращение вокруг Z
  cos = Math.cos(rotZ); sin = Math.sin(rotZ);
  x1 = x * cos - y * sin;
  y1 = x * sin + y * cos;
  
  return { x: x1, y: y1, z: z1 };
}
```

**Матрицы поворота:**
- X: наклон вперёд/назад
- Y: поворот влево/вправо
- Z: вращение по/против часовой

```javascript
  // Находим середину противоположной стороны
```

#### Биссектриса:
```javascript
function buildBisector(shape, anchorIndex) {
  const B = verts[i];
  const A = verts[(i-1+n)%n];
  const C = verts[(i+1)%n];
  
  // Единичные векторы
  const v1 = norm(sub(A, B));
  const v2 = norm(sub(C, B));
  
  // Направление биссектрисы = сумма векторов
  const bisDir = norm({ x: v1.x + v2.x, y: v1.y + v2.y });
  
  return { from: B, to: endPoint };
}
```

## 🎯 Особенности реализации

### 1. **Хранение построений**

**Было (неправильно):**
```javascript
// Локальные координаты
cons.from = shape.worldToLocal(point);
```

**Стало (правильно):**
```javascript
// Мировые координаты
cons.from = point;  // Просто сохраняем
```

**Почему:** При вращении фигуры локальные координаты не работали правильно.

---

### 2. **Выбор фигур**

**5-уровневая система:**
```javascript
// 1. hitTest
if (s.hitTest(w.x, w.y)) hitted = true;

// 2. hitTest3D (30px)
if (s.hitTest3D(w.x, w.y, 30)) hitted = true;

// 3. Bounding box (35px padding)
if (w.x >= bb.x - 35 && ...) hitted = true;

// 4. Вершины (40px)
if (Math.hypot(w.x - v.x, ...) <= 40) hitted = true;

// 5. Рёбра 3D (30px)
if (dist <= 30) hitted = true;
```

**Результат:** Очень легко попасть в фигуру!

---

### 3. **Сечения на 3D**

**Алгоритм:**
```javascript
// 1. Ищем вершины (60-80px)
for (let v of verts) {
  if (d <= vertexThreshold) best = v;
}

// 2. Ищем рёбра (40-60px)
for (let edge of edges) {
  if (dist <= edgeThreshold) best = pointOnEdge;
}

// 3. Если не нашли — место клика
return { point: w };
```

**Результат:** Можно ставить точки точно где хочешь!

## 🐛 Исправленные баги

### 1. **Построения не вращались с фигурой**

**Проблема:** Хранились в мировых координатах, не трансформировались.

**Решение:** 
```javascript
// При отрисовке трансформируем
const from = shape.localToWorld(cons.from);
const to = shape.localToWorld(cons.to);
```

---

### 2. **Сечения строились не там**

**Проблема:** `findVertexOrEdgePoint` возвращал только вершины.

**Решение:**
```javascript
// Если не нашёл вершину/ребро — возвращай место клика
if (!best.point) {
  return { point: w };  // Точное место клика
}
```

---

### 3. **Меню не видно на телефоне**

**Проблема:** Позиционирование `absolute` уходило за экран.

**Решение:**
```css
@media (max-width: 1023px) {
  .figure-menu {
    position: fixed !important;
    top: 50% !important;
    left: 50% !important;
    transform: translate(-50%, -50%) !important;
  }
}
```

---

### 4. **Тяжело попасть в вершину на телефоне**

**Проблема:** Порог 28px слишком маленький.

**Решение:**
```javascript
const isMobile = window.innerWidth <= 1023;
const vertexThreshold = isMobile ? 80 : 60;  // 80px на телефоне!
```
