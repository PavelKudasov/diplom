# Геометрический конструктор

Веб‑приложение для интерактивных геометрических построений на canvas: создание фигур (точка, отрезок, луч, прямая, окружность, прямоугольник, квадрат, треугольник, ромб, параллелограмм, трапеция, многоугольник, угол, вектор и др.), нанесение вспомогательных построений (медиана, биссектриса, серединный перпендикуляр, параллель, прямая по двум точкам, отрезок между точками), измерения и отображение свойств.

## Функциональность
- Добавление фигур через меню инструментов; для многих фигур поддерживаются перетаскиваемые вершины и вращение.
- Построения:
  - медиана (для треугольников, многоугольников и угла — к середине противоположного ребра/луча),
  - биссектриса (по внутренней биссектрисе с поиском пересечения с границей фигуры; fallback для треугольника по теореме о биссектрисе),
  - серединный перпендикуляр (ограничивается границей фигуры, иначе усечение по длине стороны),
  - прямая через две точки/вершины,
  - параллель к выбранному ребру через точку/вершину,
  - отрезок между двумя точками/вершинами.
- Расширенные лучи/прямые: достаточная длина для уверенного выбора; пересечения считаются по границам фигуры.
- Подсветка/пик: увеличенные пороги выбора вершин/рёбер для удобства работы с малыми объектами.
- Панель свойств: длины, углы, площадь (для секции), параметры угла (основание, длина лучей, значение угла в градусах), координаты вершин и построений.
- Всплывающий лог (toast, справа вверху) для информационных/ошибочных сообщений вместо консоли.

## Запуск
1. Откройте локально файл [index.html](index.html) в современном браузере **или** поднимите простой сервер:
   ```bash
   python -m http.server 8000
   ```
   затем откройте http://localhost:8000/.
2. Все зависимости встроены; сборка не требуется.

## Управление
- Выбор инструмента/фигуры — через левое меню.
- Построения требуют выбора фигуры и вершины (или двух вершин для отрезка/прямой). Для медианы/биссектрисы без выбранной вершины происходит автопривязка к ближайшей вершине.
- Перетаскивание: вершины и фигуры можно тянуть мышью; селектор показывает рамку/контуры.
- Лог/подсказки: сообщения появляются в toast; при ошибке выбора проверьте, что подсветка вершины активна.

## Структура проекта
- [index.html](index.html) — разметка страницы, подключение стилей/скриптов, холст и панели управления.
- [style.css](style.css) — оформление интерфейса, панели инструментов и тоста.
- [variables.css](variables.css) / [fonts.css](fonts.css) — переменные и шрифты (заготовки).
- [main.js](main.js) — вся логика фигур, построений, взаимодействий, свойств, логирования.
- Изображения/иконки (PNG) — ресурсы UI.

## Известные моменты и советы
- Если биссектриса/медиана не строится, убедитесь, что выбрана корректная вершина (для фигуры «Угол» вершина 0 — вершина угла, 1 и 2 — концы лучей).
- При почти вырожденных углах (≈180°) биссектриса переходит в перпендикуляр к одному из лучей.
- Для сложных фигур следите, чтобы точки выбора были внутри/на границе фигуры; при необходимости увеличьте масштаб (zoom браузера).
